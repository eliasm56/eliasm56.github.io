# Elias Manos Research Website

This is a Quarto website for `eliasm56.github.io`.

## How to build locally

1. Install Quarto: https://quarto.org/docs/get-started/
2. Open this folder in VS Code or a terminal.
3. Run:

```bash
quarto render
```

The rendered site will be written to the `docs/` folder.

## GitHub Pages setup

In the GitHub repository settings:

1. Go to **Settings → Pages**.
2. Set source to **Deploy from a branch**.
3. Choose branch: `main`.
4. Choose folder: `/docs`.
5. Save.

After pushing changes, the site should publish at:

https://eliasm56.github.io
